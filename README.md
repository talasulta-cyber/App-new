# Inventory Sync Server

هذا خادم مستقل لمزامنة بيانات محل واحد بين أجهزة Android المفعّلة. لا يغيّر خادم الترخيص القديم ولا يستخدم قاعدة بياناته؛ يحتفظ PostgreSQL هنا بالمساحات والأجهزة والكيانات وسجل العمليات. كل عملية تحمل `operationId` فريدًا، لذلك يمكن إعادة إرسالها بعد انقطاع الإنترنت دون تكرار العملية نفسها.

## متغيرات البيئة على Railway

أضف المتغيرات التالية إلى **خدمة الخادم الجديدة فقط**:

```text
SYNC_DATABASE_URL=${{Postgres.DATABASE_URL}}
SYNC_SESSION_SECRET=<قيمة عشوائية طويلة وسرية>
SYNC_ADMIN_SETUP_TOKEN=<رمز إداري مختلف وسري>
```

لا تضع القيم الحقيقية في Git أو داخل APK. يحدد Railway المتغير `PORT` تلقائيًا، والخادم يقرأه ولا يثبت منفذًا محددًا في بيئة الإنتاج. يمكن تشغيله محليًا بقيمة افتراضية `3000`.

## نشر المشروع على حساب Railway الثاني

أنشئ مشروعًا جديدًا في حساب Railway الثاني، ثم أضف قاعدة PostgreSQL وخدمة Node.js من هذا المجلد أو من مستودع Git مستقل. اربط `SYNC_DATABASE_URL` بقاعدة PostgreSQL داخل المشروع باستخدام مرجع Railway الظاهر أعلاه، ثم أضف السرّين الآخرين من صفحة Variables. أمر التشغيل هو `pnpm start`، وبعد نجاح النشر استخدم Public Networking لإنشاء نطاق HTTPS عام. لا تستخدم رابط قاعدة البيانات أو المنفذ `5432` داخل التطبيق؛ المطلوب هو نطاق خدمة Node.js العام.

عند بدء الخادم، يطبق `schema.sql` تلقائيًا بطريقة قابلة لإعادة التشغيل. افحص النتيجة بفتح:

```text
https://YOUR-SYNC-DOMAIN/health
```

يجب أن تعود استجابة JSON فيها `ok: true` و`database: "ready"`.

## إنشاء ترخيص مطابق

خادم الترخيص القديم يبقى كما هو ويظل مسؤولًا عن تفعيل التطبيق وتجديده. لأن خادم المزامنة مستقل، يجب تسجيل نسخة مطابقة من كل كود مدفوع على خادم المزامنة باستخدام الرمز الإداري، مع نفس الخطة وتاريخ الانتهاء وحد الأجهزة. لا ترسل هذا الرمز داخل APK ولا تشاركه مع المستخدمين.

مثال إداري بعد استبدال القيم محليًا:

```bash
curl -X POST "https://YOUR-SYNC-DOMAIN/v1/admin/licenses" \
  -H "Content-Type: application/json" \
  -H "x-sync-admin-token: YOUR_SYNC_ADMIN_SETUP_TOKEN" \
  -d '{"activationCode":"CODE_FROM_LICENSE_SERVER","plan":"monthly","maxDevices":3,"expiresAt":"2027-01-01T00:00:00.000Z"}'
```

لا تسجل كود التجربة المجانية على خادم المزامنة. عند إنشاء كود جديد أو تجديده على خادم الترخيص القديم، حدّث سجل الكود المطابق على خادم المزامنة قبل أن يربط المستخدم جهازًا جديدًا.

## ربط التطبيق

افتح التطبيق ثم انتقل إلى **المزيد ← الإعدادات ← المزامنة بين الأجهزة**، وأدخل رابط خادم Node.js العام، مثل:

```text
https://YOUR-SYNC-DOMAIN
```

لا تضع `/health` ولا `/v1/sync/register` في الحقل؛ التطبيق يضيف مسارات API تلقائيًا. بعد حفظ العنوان، فعّل التطبيق بالكود المعتاد من خادم الترخيص القديم. عند نجاح التفعيل، يسجل التطبيق الجهاز في خادم المزامنة. كرر العملية على الجهازين الثاني والثالث بالكود نفسه، ما دام `maxDevices` يسمح بذلك.

## سلوك المزامنة

يعمل التطبيق محليًا حتى عند انقطاع الإنترنت. عند الحفظ يضيف التغيير إلى طابور محلي، ويحاول رفعه فورًا، ثم يعيد المحاولة عند فتح التطبيق أو عودته إلى الواجهة. تسحب الأجهزة العمليات الجديدة باستخدام cursor، وتُدمج القوائم كإضافات وتعديلات وحذوفات بدل استبدال القائمة كاملة. يشمل ذلك المنتجات والفواتير والديون والعملاء والمستودعات والمصاريف وإعدادات الماسح والاسم التجاري.

يوفر الخادم المسارات التالية:

| المسار | الغرض |
|---|---|
| `GET /health` | فحص الخدمة وقاعدة البيانات |
| `POST /v1/admin/licenses` | إنشاء أو تحديث ترخيص محلي لخدمة المزامنة |
| `POST /v1/sync/register` | تسجيل جهاز والتحقق من الترخيص وحد الأجهزة |
| `POST /v1/sync/push` | رفع دفعة عمليات idempotent |
| `POST /v1/sync/pull` | سحب العمليات بعد cursor رقمي |
| `GET /v1/sync/snapshot` | قراءة الحالة المركزية الحالية للجلسة |
| `POST /v1/sync/heartbeat` | تحديث آخر ظهور للجهاز |

## التشغيل والاختبار المحلي

```bash
pnpm install
pnpm test
pnpm start
```

تتحقق الاختبارات من عزل المساحات، وحماية العمليات المكررة، والتحقق من الجهاز والترخيص، وسلوك الدفع idempotent. يحتاج التشغيل الكامل إلى PostgreSQL مضبوط في `SYNC_DATABASE_URL`.

## حدود مهمة

المزامنة لا تستبدل نظام الترخيص القديم ولا تعدّل مشروع Railway الأول. وهي لا تنشئ بيانات مراجعات أو تقييمات أو محتوى مستخدمين؛ تنقل فقط بيانات التطبيق التي حفظها المستخدم. يجب حفظ `SYNC_SESSION_SECRET` و`SYNC_ADMIN_SETUP_TOKEN` خارج المستودع وتغييرهما إذا ظهرا لأي شخص غير مخول.
